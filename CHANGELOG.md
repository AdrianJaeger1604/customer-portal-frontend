## [0.3.0] - 2025-01-28

### Added
- Desktop navigation component with dropdown menus (PORT-4)
- React Router integration for navigation
- Unit tests for navigation component (>85% coverage)
- Accessibility tests with jest-axe
- Storybook documentation for navigation

### Changed
- Updated design system with new color palette
- Improved TypeScript type definitions
- Enhanced error handling in API service

### Fixed
- Navigation hover states not working in Safari
- Console warnings from React key props

### Documentation
- Added architecture overview documentation
- Updated setup guide with troubleshooting section

---

- Navigation design and information architecture (PORT-3)
